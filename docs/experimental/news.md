# News feed (experimental)

## What it does

Converts `news.md` in the data directory into an RSS feed shown on the login page.

## How to enable

- Master + `experimental.news: true` or `EXPERIMENTAL_NEWS=1`
- Add `news.md` under `MSS_LOGIN_DATA_DIR` (see `readme/news_feed_template.md`)

## When it is required

Optional. Not required for core security features.
