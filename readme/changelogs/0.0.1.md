# 0.0.1 - Initial Release

* Initial release
* Added initial security implementations (based off [ComfyUI-Usgromana](https://github.com/DayMan84/ComfyUI-Usgromana))
* Expanded the feature set of the custom node to include the following:
  * JWT tokens (expiring by default and non-expiring-defaulting to Admin accesible only)
  * Permission based access to the ComfyUI console
  * Granular permissions for models, emeddings, LoRAs, etc.
  * PostgreSQL database implementation along with SQLite database implemetatiom (with added, scaled, optional, encryption)
  * And MUCH more!
* Added an agentic ruleset (found in the [.agent](../.agent/rules/secure-coding-practices.mdc) folder, under `rules`) for enhanced security when adding code using IDEs and agents such as Cursor AI, Gemini, Claude, etc.
* Added a DEBUG_MODE functionality/toolset, which can be toggled using the config under the user directory, or by enabling the `DEBUG_MODE` enviornment variable (by setting `DEBUG_MODE` to `true` or `1`)
  * This will enable **MUCH** more detailed logging, and is useful for narrowing down issues with authentication, etc.
  * **WARNING!!!** `DEBUG_MODE` will output sensitive information (such as raw JWT tokens, prompts, IP addresses, etc.) to the console and to a log file on the host system of ComfyUI. So **ONLY** use this feature when you absolutely need to!!!
