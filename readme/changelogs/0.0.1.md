# 0.0.1 - Initial Release

## Changelog

- Initial release
- Added initial security improvements and completely overhauled the code of [ComfyUI-Usgromana](https://github.com/DayMan84/ComfyUI-Usgromana), which this node is built on top of.
- Expanded the feature set of the custom node to include the following:
  - JWT tokens (expiring by default and non-expiring-defaulting to Admin accessible only)
  - Permission based access to the ComfyUI console
  - Granular permissions for models, embeddings, LoRAs, etc.
  - PostgreSQL database implementation along with SQLite database implementation (with added, scaled, optional, encryption)
  - And MUCH more!
  - Added multiple agentic rulesets (found in the [.agent](../.agent/rules/) folder, under `rules`) for enhanced security when adding code using IDEs and agents such as Cursor AI, Gemini, Claude, etc. along with other useful instructions
  - Added a DEBUG_MODE flag, which can be toggled using the config under the user directory, or by enabling the `DEBUG_MODE` environment variable (by setting `DEBUG_MODE` to `true` or `1`)
    - This will enable **MUCH** more detailed logging, and is useful for narrowing down issues with authentication, etc.
    - **WARNING!!!** `DEBUG_MODE` will output sensitive information (such as raw JWT tokens, prompts, IP addresses, etc.) to the console and to a log file on the host system of ComfyUI. So **ONLY** use this feature when you absolutely need to!!!
  - Sanitized input of various kinds.
  - Moved data directory outside of node path, to help keep persistency between installs.
  - Added an `owner` role, which will be given to the most senior admin, or the first user created.
  - Added and implemented a self-updating system (still a WIP).
  - Enhanced JWT tokens by making them auto-expire after a configurable time.
    - Added JWT labelling, for easier tracking of JWT tokens and their usage.
  - Migrated database configurations into one, coherent, database.
  - Added a changelog information system, news system, and update notification system.
  - Added some experimental features (**⚠️ USE AT YOUR OWNRISK!!! ⚠️**)
    - More to come on these features later.
  - System stability and performance improvements.
  - Removed Herobrine.
