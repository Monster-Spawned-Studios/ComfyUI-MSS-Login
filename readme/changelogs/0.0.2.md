# 0.0.2 - System Stability and Performance Improvements

## Changelog

- Added a [`CLAUDE.md`](../../CLAUDE.md) file for easier integration with the Anthropic series of AI models.
- Changed the `.cursor` folder out for a [`.agents`](../../.agents/) folder, also updating the [`AGENTS.md`](../../AGENTS.md) file for cross-agent compatibility.
- Moved node storage to a directory (that is configurable) that exists outside the node folder, so as to not be overwritten every time the node updates.
- Enhanced and updated the loading screen, update system, MFA system, news system, and S3 implementation.
- Made the S3 implementation (which is an experimental feature) more cross-platform friendly, using `boto3` as a dependency.
- Added some additional test scripts for CI/CD purposes under the [`scripts`](../../scripts/) folder.
